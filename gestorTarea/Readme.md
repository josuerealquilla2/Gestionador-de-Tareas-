# Gestor de Tareas

## Descripción
Aplicación Django para crear y gestionar tareas.
## funciones
marcar y desmarcar tareas completados 
anadir tareas desde html 
ver lista de tareas 

## Instalación
```bash
git clone <url-del-repositorio>
cd Gestor-Tareas
python -m venv .venv
.venv\Scripts\activate  # Windows
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
